# Aero7Qt

Aero7Qt is a clean-room, header-only Qt 6 compatibility layer for Aero7
companion applications. It supplies original code-drawn controls and styling;
it contains no files from `libAeroQt` and no Microsoft artwork, sounds, fonts,
or trademarks.

The public API is intentionally small and Aero7-specific. Consumers should use
the `Aero7Qt::Aero7Qt` CMake target and the `Aero7` C++ namespace.
