# Aero7 companion emblem provenance

File: `aero7-companion.png`

Refreshed on 2026-08-03 with the copyright-free, AI-generated circular Aero7 7
emblem supplied by the project owner. OpenAI's built-in image editor was asked
to preserve the emblem while placing it on a flat chroma background. That
background was removed, and the transparent result was cropped, centered, and
scaled mechanically. The package copies and the 46-pixel SevenStart normal,
hover, and pressed sprites are UI variants of the same source artwork. The
standalone 7 supplied at the same time is used in the transparent Aero7
Welcome/logout watermark.

The Aero7 project owner represents this supplied asset as copyright-free and
approves it for distribution with Aero7. No bitmap from the audited companion
repositories is included. The previous orb sprite is retained under
`packages/aerothemeplasma-desktop-git/legacy-logo-backups/` for rollback and is
not installed by the package.
